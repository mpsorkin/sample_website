# Trail Finder

Trail Finder is a simple sample website that helps users choose a hiking trail based on their experience level and available time.

## Project Files

This project includes:

- `index.html`
- `index.css`
- `script.js`
- `README.md`

## Website Features

- A homepage with a hero section
- Navigation links
- Trail information cards
- Responsive design for smaller screens
- JavaScript logic that takes user input and displays a recommendation

## How the JavaScript Works

The user chooses:

1. Their hiking experience level
2. How much time they have available

When the user clicks the recommendation button, JavaScript checks the selected values and displays a trail recommendation.

## Purpose

This website was created as a sample project to demonstrate HTML structure, CSS styling, responsive design, and basic JavaScript functionality.
